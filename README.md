# 🍣 Sushi Restaurant POS System

Система управления суши-рестораном с поддержкой русского и польского языков.

## 📋 Возможности

### ✨ Основные функции:
- **Управление столами** - отслеживание занятых/свободных столов
- **Прием заказов** - для столов и доставки
- **Меню** - 19 блюд с категориями (роллы, маки, нигири, горячие блюда, супы, напитки, десерты, сеты)
- **Кухня** - отображение заказов на приготовление
- **Склад** - учет ингредиентов с автоматическим списанием
- **Доставка** - управление заказами на доставку
- **Статистика** - финансовая отчетность и популярные блюда
- **Печать** - кухонные чеки и дневные отчеты

### 🌐 Языки:
- Русский (RU)
- Polski (PL)

## 🚀 Запуск

### 1. Запуск сервера (Backend):
```bash
cd backend
python main.py
```
Сервер запустится на `http://127.0.0.1:8000`

### 2. Открыть приложение (Frontend):
Откройте файл `frontend/index.html` в браузере или используйте локальный сервер.

## 📱 Использование

### Главный экран (Dashboard):
- **Выручка** - общая сумма закрытых заказов
- **Заказы** - количество всех заказов
- **Столы** - сколько столов занято из 12
- **Оповещения** - предупреждения о заканчивающихся продуктах

### Быстрые действия:
1. **Новый заказ** - создание заказа для стола или доставки
2. **Столы** - просмотр и управление столами
3. **Меню** - просмотр блюд по категориям
4. **Кухня** - заказы на приготовление
5. **Склад** - учет ингредиентов
6. **Статистика** - финансовая отчетность

### Создание заказа:
1. Нажмите "Новый заказ" или выберите блюдо в меню
2. Выберите тип: "Стол" или "Доставка"
3. Добавьте блюда в корзину
4. Укажите детали (стол или адрес доставки)
5. Нажмите "Создать заказ"

### Управление кухней:
- **Открытые заказы** - новые заказы
- **Начать готовить** - перевод в статус "Готовится"
- **Готово** - заказ готов к выдаче
- **Печать чека** - отправка на кухонный принтер

### Складской учет:
- Автоматическое списание ингредиентов при создании заказа
- Предупреждения о заканчивающихся продуктах
- Ручное списание (порча, истечение срока)

### Доставка:
- Создание заказа с адресом доставки
- Отслеживание статуса: Ожидает → Готовится → В пути → Доставлен

## 🗄️ База данных

### Меню (19 позиций):
- **Суши-роллы**: Филадельфия, Калифорния, Дракон
- **Маки**: с лососем, с огурцом
- **Нигири**: с лососем, с тунцом
- **Сашими**: микс
- **Горячие блюда**: Темпура креветки, Рамен с курицей, Якитори
- **Супы**: Мисо суп
- **Напитки**: Зеленый чай, Саке, Асахи пиво
- **Десерты**: Моти микс, Мороженое
- **Сеты**: Премиум, Вечеринка

### Склад (15 ингредиентов):
- Рыба: лосось, тунец, угорь
- Овощи: авокадо, огурец
- Бакалея: рис, нори, сливочный сыр
- Соусы: унаги, икра масаго
- Морепродукты: креветки
- Мясо: куриное филе
- Прочее: паста мисо, тофу, водоросли вакаме

## 🔧 API Endpoints

### Основные:
- `GET /status` - статус сервера
- `GET /tables` - список столов
- `GET /menu` - меню с категориями
- `POST /orders` - создание заказа
- `GET /orders` - список заказов
- `GET /kitchen/orders` - заказы на кухню
- `GET /inventory` - склад
- `POST /inventory/write-off` - списание
- `GET /statistics/financial` - финансовая статистика
- `GET /deliveries` - доставки
- `GET /print/ticket/{id}` - печать чека

## 💡 Особенности

- **Автоматический расчет** - списание ингредиентов по рецептам
- **Мультивалютность** - рубли (₽) для RU, злотые (zł) для PL
- **Мобильный интерфейс** - адаптирован для планшетов и смартфонов
- **Темная тема** - современный дизайн с приятными цветами
- **Быстрые уведомления** - toast-сообщения о действиях

## 📊 Статистика

- Общая выручка
- Прибыль (выручка минус списания)
- Всего заказов
- Средний чек
- Стоимость склада
- Популярные блюда

## 🖨️ Печать

- **Кухонные чеки** - с составом заказа и заметками
- **Дневные отчеты** - с разбивкой по методам оплаты
