# 🔓 КАК СДЕЛАТЬ РЕПОЗИТОРИЙ ПУБЛИЧНЫМ

## Проблема:
Ваш репозиторий **приватный (private)**, поэтому GitHub Pages недоступен.

## Решение: Сделать репозиторий публичным

### Шаг 1: Перейдите в настройки репозитория

1. Откройте: https://github.com/denisklyuchko-design/mango
2. Перейдите во вкладку **"Settings"** (вверху)

### Шаг 2: Найдите раздел Danger Zone

1. Прокрутите страницу вниз до раздела **"Danger Zone"** (красная рамка)
2. Найдите пункт **"Change visibility"**

### Шаг 3: Измените видимость

1. Нажмите кнопку **"Change visibility"**
2. Выберите **"Make public"**
3. Подтвердите, введя имя репозитория: `denisklyuchko-design/mango`
4. Нажмите **"I understand, make this repository public"**

### Шаг 4: Проверьте

После этого:
- Репозиторий станет публичным
- GitHub Pages станет доступен
- Вы сможете включить Pages как описано в инструкциях

## 📋 Что делать дальше:

### 1. Загрузите файл telegram_app.html

1. В репозитории нажмите **"Add file"** → **"Upload files"**
2. Перетащите файл `frontend/telegram_app.html`
3. Нажмите **"Commit changes"**

### 2. Включите GitHub Pages

1. Settings → Pages
2. Source: "Deploy from a branch"
3. Branch: "main" → "/ (root)"
4. Нажмите "Save"

### 3. Проверьте

1. Подождите 1-2 минуты
2. Откройте: https://denisklyuchko-design.github.io/mango/telegram_app.html

## 🎯 Альтернативные варианты:

Если не хотите делать репозиторий публичным:

### Вариант 1: Vercel (бесплатно, приватно)

1. Зарегистрируйтесь: https://vercel.com
2. Импортируйте приватный репозиторий
3. Vercel развернет сайт
4. Ссылка: `https://mango-telegram-app.vercel.app/telegram_app.html`

### Вариант 2: Netlify (бесплатно, приватно)

1. Зарегистрируйтесь: https://netlify.com
2. Подключите приватный репозиторий
3. Netlify развернет сайт
4. Ссылка: `https://mango-sushi-wok.netlify.app/telegram_app.html`

### Вариант 3: Локальный хостинг

Если у вас есть свой хостинг:
1. Загрузите файл `telegram_app.html` на хостинг
2. Получите ссылку: `https://ваш-домен.com/telegram_app.html`

## ⚠️ Важно:

- **GitHub Pages работает только с публичными репозиториями** (бесплатно)
- Для приватных репозиториев нужен GitHub Enterprise (платно)
- **Vercel и Netlify работают с приватными репозиториями бесплатно**

## 📞 Если не получается:

1. Убедитесь, что вы владелец репозитория
2. Проверьте, что вошли в правильный аккаунт
3. Попробуйте обновить страницу после изменения видимости

**Сделайте репозиторий публичным или используйте Vercel/Netlify!** 🍀
