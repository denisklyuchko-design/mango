# 🚀 ПРОСТАЯ НАСТРОЙКА GITHUB PAGES (БЕЗ GIT)

## ⚠️ ВАЖНО: GitHub Pages еще не настроен!

Вы видите ошибку 404, потому что GitHub Pages не включен в вашем репозитории.

---

## 📝 ШАГ 1: Установите Git (если еще не установлен)

1. Скачайте Git: https://git-scm.com/download/win
2. Установите Git (согласитесь на все настройки по умолчанию)
3. Перезапустите компьютер

---

## 📝 ШАГ 2: Загрузите файлы на GitHub

### Вариант A: Через GitHub Desktop (проще)

1. Скачайте GitHub Desktop: https://desktop.github.com/
2. Установите и войдите в свой аккаунт GitHub
3. Откройте GitHub Desktop
4. Нажмите **File** → **Add Local Repository** → **Choose...**
5. Выберите папку `c:\pos_project`
6. Нажмите **Create repository**
7. Нажмите **Publish repository**
8. Введите имя: `mango_pos`
9. Убедитесь, что стоит галочка **Keep this code private** (если хотите приватный)
10. Нажмите **Publish repository**

### Вариант B: Через командную строку

1. Откройте командную строку (cmd)
2. Введите команды по очереди:

```bash
cd c:\pos_project
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/mango_pos.git
git push -u origin main
```

**Замените `ВАШ_НИК` на ваш логин GitHub!**

---

## 📝 ШАГ 3: Включите GitHub Pages

1. Откройте ваш репозиторий на GitHub: https://github.com/ВАШ_НИК/mango_pos
2. Нажмите **Settings** (вверху)
3. В левом меню нажмите **Pages**
4. В разделе **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`
   - **Branch**: выберите `main` и `/ (root)`
5. Нажмите **Save**
6. **Подождите 2-3 минуты**

---

## 📝 ШАГ 4: Проверьте ссылку

После настройки GitHub Pages, ваша ссылка будет:
```
https://ВАШ_НИК.github.io/mango_pos/frontend/index_final.html
```

**Откройте эту ссылку в браузере!**

---

## 📝 ШАГ 5: Настройте Telegram бота

1. Откройте **BotFather** в Telegram
2. Отправьте `/mybots` и выберите вашего бота
3. Нажмите **Bot Settings** → **Menu Button** → **Configure Menu Button**
4. Отправьте ссылку: `https://ВАШ_НИК.github.io/mango_pos/frontend/index_final.html`
5. Введите название кнопки: `🍱 Меню`

---

## 📝 ШАГ 6: Запустите бота

1. Откройте командную строку
2. Введите:
```bash
cd c:\pos_project\backend
python telegram_bot.py
```

---

## ❓ ЧАСТЫЕ ПРОБЛЕМЫ

### ❌ Ошибка 404
**Решение:** GitHub Pages еще не настроен. Следуйте ШАГУ 3.

### ❌ Файл не найден
**Решение:** Убедитесь, что файл `frontend/index_final.html` существует в репозитории.

### ❌ Git не установлен
**Решение:** Установите Git (ШАГ 1) или используйте GitHub Desktop.

### ❌ Не могу загрузить файлы
**Решение:** Убедитесь, что вы вошли в GitHub и у вас есть доступ к репозиторию.
